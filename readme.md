# PBO JavaScript - Materi dan Contoh Kode

Repositori ini berisi kumpulan materi dan contoh kode Praktikum Pemrograman Berorientasi Objek (PBO) menggunakan JavaScript. Setiap folder dan file di dalam repositori ini mewakili konsep OOP seperti inheritance, polimorfisme, abstraksi, dan interface, serta contoh penerapannya dalam bahasa JavaScript modern (ES6+).

## Struktur Folder & Penjelasan

- **MateriPerkuliahan/tugas3/**
  - `before.js` & `after.js`: Contoh perbandingan OOP sebelum dan sesudah ES6 (function constructor vs class).
- **MateriPerkuliahan/tugas4/**
  - `index.js`: Contoh penggunaan public, private, dan protected property/method pada class.
- **MateriPerkuliahan/tugas5/**
  - `inheritance.js`: Contoh pewarisan (inheritance) antar class.
  - `polimorfism.js`: Contoh polimorfisme dengan berbagai bentuk class dan method override.
- **MateriPerkuliahan/tugas6/**
  - `abstraction.js`: Contoh abstraksi dengan class abstrak dan implementasinya.
  - `interface.js`: Simulasi konsep interface pada JavaScript dengan class abstrak.

## Cara Menjalankan

1. Pastikan Anda sudah menginstall [Node.js](https://nodejs.org/).
2. Buka terminal di folder project ini.
3. Jalankan file yang diinginkan menggunakan perintah berikut:
   
   ```bash
   node MateriPerkuliahan/tugas3/before.js
   node MateriPerkuliahan/tugas3/after.js
   node MateriPerkuliahan/tugas4/index.js
   node MateriPerkuliahan/tugas5/inheritance.js
   node MateriPerkuliahan/tugas5/polimorfism.js
   node MateriPerkuliahan/tugas6/abstraction.js
   node MateriPerkuliahan/tugas6/interface.js
   ```
4. Output akan muncul di terminal sesuai dengan contoh kode yang dijalankan.
